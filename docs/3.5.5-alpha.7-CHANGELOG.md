## Validation

Automated release checks cover compilation, unit tests, lint and the existing glass geometry/shading checks. A device visual test is still required for compositor behavior.

1. Keep Windowed Glass selected and enable Screenshot Mode. Open a fullscreen app with recognizable text or icons.
2. Slowly unfold and pause halfway. Check that text does not appear twice through the distorted section, and that the untouched section shows a clean captured image.
3. Finish opening, then slowly fold and repeat the midpoint check. Try moving content in the app to distinguish a visible live layer from the frozen outgoing image.
4. Report whether duplicate content occurs on the cover, inner screen or both. Copy the screenshot-mode test report. Treat the final display-off/on event separately for this test.
