# 3.5.8-alpha.2 — Separate motion sensitivity

- Separate cover and inner screen sensitivity sliders, each 0–200%.
- Existing sensitivity initializes both controls; each saves independently.
- The reflected glass preview on the inner display uses inner sensitivity.
- Reset motion settings restores both to 100%. Status reports show both values.
- Retains alpha.1 startup settling and dead zone; smoothing and direction remain shared.
- GitHub prerelease only; stable and Play unchanged.
