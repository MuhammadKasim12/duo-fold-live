Based on alpha.28, not a stable release. Alpha.20 remains the stable rollback checkpoint.

- Resolve stale real-size bounds against current display mode and rotation for the retained host and live shader validation. Preserve scaled logical dimensions when their aspect ratio agrees.
- Retain an already-visible active normal-mode host through a transient OFF snapshot only while interactive, unlocked and receiving fresh allowed angles, bounded to 600 ms. Actual screen-off clears the bridge; normal sleep and lock handling remain active.
- Retain one recent capture and, on a closing remap, allow a recent inner capture (at most 300 ms old when armed, matching rotation) to be projected through the existing cover shader for at most 600 ms. It is temporary outgoing content, not a fresh cover capture. Fresh valid destination content takes priority. The bridge cannot signal destination readiness.
