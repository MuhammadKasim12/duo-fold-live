# 3.5.8-alpha.10 — regional compositor blur

Both compositor experiments replace the uniform 40 px whole-surface blur with
non-overlapping blur regions. Cover blur advances from the right edge across the
panel as it opens; inner blur advances from the left toward the midpoint while
closing. The inner clean half is excluded. The canonical mask rotates with the
existing renderer and reverses with fold progress; 24 bands feather the radius.

A separate System blur radius control (0–240 px, default 120) adjusts actual radius.
Glass strength scales radius rather than tint. The projected compositor path
sets shader darkening to zero. Regions use constant alpha and no color fill.
Blur naturally averages neighboring colors; this is not a promise of identical
pixel brightness, especially near high-contrast edges or projected black margins.

Both modes share an owned blur child, synchronized with the renderer buffer.
Fallback/endpoint clear hides its regions, and standby/destruction removes it.
An unsupported region API reports a failure and falls back to unblurred projection,
never silently reverting to whole-screen blur. Diagnostics include region count
and requested peak radius. Transaction acceptance is not optical proof.

Normal glass shader and blur settings, motion behavior and handoff gates are unchanged.
No speed advantage is claimed. Device testing is needed for strength, boundary
smoothness, clean-half preservation, rotation, and endpoint cleanup.

Unit tests cover clean-half exclusion in all rotations, moving cover boundary,
radius-only intensity changes, finite bounds, zero blur and non-overlapping regions.
