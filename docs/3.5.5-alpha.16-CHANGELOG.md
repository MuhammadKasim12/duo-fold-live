# 3.5.5-alpha.16

- Wallpaper preview claims its own touch gestures so dragging does not scroll the page. Pinch zoom is anchored under the fingers, with drag and zoom sharing the existing saved crop settings. All sliders, buttons, save/discard, and advanced controls are unchanged.
- Screenshot endpoint reveal starts on the first exact-task READY + HAS_DRAWN verification, rather than waiting for a second verification and another 64 ms settle. Readiness has its own client queue and retries without the previous 150 ms delay.
- Reveal duration is 160 ms. The 1800 ms emergency deadline remains bounded. Lock, sleep, mode changes and stale connection cleanup remain.
- Native concurrent cancellation is submitted before task-list/window diagnostics. Physical-screen handoff remains at the endpoint; the 12-degree fade and normal Live Screen behavior are unchanged.
- Added handoff-to-reveal timing in endpoint fade diagnostics. Samsung native remap time is not guaranteed to improve; compare on-device timing and visual continuity.
