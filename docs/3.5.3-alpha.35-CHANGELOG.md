# 3.5.3-alpha.35 — Quick Settings tile

- Add Duo Fold Live to Quick Settings using Samsung's panel editor.
- Tap to switch animation on/off using the existing enabled preference; tile reflects in-app changes while listening and refreshes whenever opened.
- Long-press opens Duo settings using Android's tile preferences action.
- Unlock is required for a locked-screen tap; incomplete setup opens the app without enabling animation.
- Wallpaper settings, animation selection/tuning, and alpha.34 recovery are unchanged.

Check on device: add tile, toggle both ways, change enabled in app and reopen panel, long-press, and try while locked. Build checks do not substitute for Samsung UI verification.
