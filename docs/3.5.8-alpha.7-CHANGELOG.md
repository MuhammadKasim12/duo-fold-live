# 3.5.8-alpha.7 — unmasked handoff baseline

Experimental comparison with alpha.6. Normal live handoff bypasses the inner preview pre-release gate and the prepared cover pre-switch gate. HandoffFade black layers and PreviewExpansion/PreparedCoverLayer holds are disabled. The normal display-state request proceeds at the existing threshold while glass catches up afterward.

Prewarm, hinge thresholds, renderer preparation, blur, motion settings, screenshot routing, lock checks and stale-angle handling are unchanged. Visual gaps, wallpaper exposure and incorrect interim geometry are expected. This is a diagnostic baseline, not a polished release or a claim of minimum hardware latency.

Compare alpha.6 and alpha.7 using the same fullscreen app, fold speed and settings in both directions. Record threshold/request, physical remap, panel ON, and glass commit separately. Preparation bypass does not remove Android transition work or renderer/capture latency. Diagnostic report identifies the baseline explicitly.
