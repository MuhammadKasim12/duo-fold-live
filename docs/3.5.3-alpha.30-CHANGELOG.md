# 3.5.3-alpha.30 — Duo Classic motion and Screenshot Mode test gate

- Duo Classic uses the same dedicated shader under Live Screen and Screenshot Mode.
- Cover unfolding uses a smooth stretch capped at 1.28×, avoiding the old near-singular end stretch.
- Inner closing compresses the affected half toward the hinge; opening reverses that curve. Rotation-aware mapping preserves the unaffected half.
- Classic blur is 1.5 (versus the normal default 0.3); glass shading is at least 1.8 (versus 1.0). Other styles and their saved controls remain unchanged.
- Normal Screenshot Mode taps show Coming soon / in the final stages of active development. Existing screenshot selections migrate to Live Screen until unlocked.
- Hold the Screenshot Mode row continuously for 10 seconds to unlock and select it for testing. Unlock persists locally across app restarts. The Developer toggle cannot bypass the gate.
- Screenshot implementation remains experimental; this does not fix ghosting. Endpoint screenshot hold and endpoint black fade remain disabled.

Reference stills inform the geometry; exact motion and visual quality require device validation. No display-power or orientation logic changed.
