# 3.5.3-alpha.37 — wallpaper feasibility test

Developer settings: Photo wallpaper hinge test.

Adds a real photo WallpaperService and system picker entry. This is a baseline feasibility test: it does not independently host or force Samsung’s engine to remain active. It measures whether existing hinge replies survive Android’s wallpaper selection/lifecycle. Fresh changing angles on Home must be verified on both panels; preview success is insufficient.

The test explicitly disables the existing custom photo layer and remembers its previous preference so the old layer cannot mask the result. Canceling the picker also leaves this layer disabled until restored using the test screen. No wallpaper binding changes occur on upgrade. Application/destination is controlled by Android’s picker; select Home only or cancel. Restore Samsung Home bindings with the existing repair flow, then restore the prior photo-layer preference. No Samsung APKs or decompiled code are included.

Test: apply Home only, fold/unfold on Home, sleep/unlock folded and unfolded, copy the report. Lifecycle logs include visible/preview state and sampled angles. Loss of fresh changing angles means this baseline route fails and separate Samsung engine hosting needs further investigation. No unlock-flash fix is claimed.
