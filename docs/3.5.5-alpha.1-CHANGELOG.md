# 3.5.5-alpha.1 — Cover startup experiment

This alpha tests the unanimated-content flash at the start of closing. Stable
3.5.4 remains the rollback build. This is not yet a verified device fix.

- In normal Windowed Glass mode, retain the primary overlay, composition and
  capture client during an unlocked, fresh-angle inner-to-cover remap. Update
  panel geometry and request a fresh capture immediately instead of destroying
  and recreating the overlay after the cover is already ON.
- Record a bounded cover-startup trace: app-observed remap, first cover capture,
  fallback changes, host alpha and first glass frame transaction commit. These
  are software observations, not optical visibility or blackout durations.
- Reject captured frames with the wrong rotation as well as the wrong dimensions.
- Include glass strength and blur amount in the status report.
- Preserve 3.5.4's Android-owned closing release with its 1000 ms fallback,
  Smooth/Fast presets, shader geometry and shading curves.

## Device test

Use normal Live Screen / Windowed Glass with the same strength, blur and smoothing
for the comparison. Open fully, wait two seconds, then close at a normal quick
pace five times. Check for the initial unanimated flash, correct cover sizing,
and continued cover power after full closure. Copy a report after a failed
cycle (or after the fifth clean cycle), waiting four seconds after closure so
endpoint sampling can finish. Repeat one cycle in landscape.

For the separate dark-boundary issue, film a slow close from fully open with a
second device, keeping the affected screen visible. Pause where the dark boundary
starts retreating and note whether this is before or after the cover handoff.
Start at 100% glass strength, then repeat at the stronger setting if useful.
The current shader is deliberately unchanged in this startup experiment.

## Shading investigation

The Windowed Glass shader uses the original projected `edge` for darkening/blur,
but V2 uses an adjusted source-coordinate mapping for stretch. A scalar evaluation
of the existing inner shader at the outer edge, intensity 1, gives darkening of
approximately 0.148, 0.487, 0.718, 0.596, 0.314 and 0.013 at projection angles
15, 30, 45, 60, 70 and 80 degrees. These are shader angles, not physical hinge
angles, and exclude image-content/blur contributions. This supports a shading
reversal as a candidate for the reported retreat; a slow physical-screen video
is still needed to associate that calculation with the observed effect.
