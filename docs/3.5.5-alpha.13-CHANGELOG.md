In the latest close both overrides were accepted by 447945374, the incoming physical panel reported OFF at 447945432–447945459, and ON at 447945511. Override release began much later, at 447947344. - Preserve the alpha.10 ghosting fix, handoff angles, existing ON-hold settings and bounded cleanup, normal live behavior and wallpaper behavior. This build targets app-side recovery, not physical power control.

## Framework inspection

AOSP LogicalDisplayMapper marks transitioning displays for OFF, waits for transitioning devices to report OFF (or a forced timeout), then applies the new layout. That is consistent with the observed remap interruption even while the device stays interactive. This is a reference implementation, not verification of Samsung's exact Android 17 service or the precedence of its vendor override. No private framework patch or guessed power API is introduced.

Source: https://android.googlesource.com/platform/frameworks/base/+/main/services/core/java/com/android/server/display/LogicalDisplayMapper.java (setDeviceStateLocked, areAllTransitioningDisplaysOffLocked, finishStateTransitionLocked).
