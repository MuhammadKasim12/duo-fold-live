## Repeatable handset run

1. Install over the current build; do not uninstall, reset settings or change smoothing/fades. Let startup settle for about 15 seconds.
2. Stay on the same Home page in portrait. Keep wallpaper, refresh-rate, brightness and power-saving settings unchanged between builds.
3. Perform five full open/close cycles, moving at roughly the same speed and pausing two seconds fully open and fully closed. Avoid power-button presses during the run; record any recovery presses separately if a screen stays dark.
4. Immediately copy the full report and describe dark screens, stutter or visible handoff changes. These observations remain necessary: commit timestamps are not optical measurements.
5. Repeat the same run on the comparison candidate in a follow-up, with unchanged settings. Compare cover remap-to-first-glass-commit samples and inner preview hold times separately. Do not mix native panel ON time with full animation recovery or infer display FPS from submitted-frame samples.

Build validation: exact baseline source comparison, shader geometry checks, release unit tests, lint, APK assembly and signature verification. Device timing and visible reliability require the run above.
