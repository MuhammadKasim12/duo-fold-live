# Duo Fold Live 3.5.7

- Adds optional Motion-Tracked Glass, including panel-specific anchoring and a smooth return to the fully open inner display.
- Places motion controls below Full-resolution glass, with extra settings shown only while enabled. Off by default; existing preferences are preserved.
- Moves custom wallpaper above Folding Animation Style and combines its invitation into one tappable panel.
- Replaces the wallpaper editor's large banner with a compact Custom Wallpaper heading.
- Includes the tested shared Play flavor and privacy controls. Play packages remain in the private build repository.

The final change from 3.5.7-alpha.9 is the compact wallpaper editor heading; animation behavior is unchanged.
