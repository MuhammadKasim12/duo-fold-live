# 3.5.3-alpha.32 — Duo Classic tuning

Duo Classic only:
- Inner-display vertical compression increased 37.5% relative to the saved value (default 40% → effective 55%; capped at the existing 200% limit). Cover compression unchanged.
- Glass strength reduced 30% from alpha.31 (default effective 1.8 → 1.26).
- Blur increased 25% (1.5 → 1.875).

Other animation modes, horizontal geometry, previews, and Screenshot Mode gate remain unchanged. Device validation is still required for visual results.
