# Duo Fold Live 3.5.3

Stable release based on 3.5.3-alpha.41, with the approved animation-description edits.

- Windowed Glass, Duo Classic, and adjustable Plain Fade animation styles.
- Separate Fold & Unfold, Fold-Only, and Unfold-Only behavior controls.
- Quick Settings tile for toggling Duo Fold Live.
- Running-notification settings and optional support-notification controls.
- Capture recovery after waking and unlocking.
- Plain Fade controls for wipe travel, timing, softness, darkness, and brightness on each display, with a black inner-display hold before handoff.
- Updated Duo Classic description and removed the Plain Fade description.

Experimental wallpaper tests remain opt-in in Developer settings. The alternative wallpaper route is still experimental and is not an unlock-flash fix.
