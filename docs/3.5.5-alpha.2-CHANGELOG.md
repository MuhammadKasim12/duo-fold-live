# Duo Fold Live 3.5.5-alpha.2

- Windowed Glass shading now uses physical panel coordinates instead of the projected, stretching screenshot coordinates. The inner dark boundary advances with fold progress without reversing as projection approaches edge-on. Existing stretch geometry, landscape orientation and clean right preview are retained.
- Adds opt-in direct root access in Connection & setup and first-run setup. Already-rooted users can authorize their root manager instead of installing Shizuku. Existing installations retain Shizuku unless root access is explicitly granted. This does not root a device.
- Preserves Android-controlled cover-close release with its 1000 ms fallback and the retained-overlay startup diagnostic from alpha.1.

Validation: scalar tests exercise actual shader functions for bounded monotonic shading; existing stretch tests remain in CI. Root transport uses libsu service 6.0.0 and must be tested on a rooted Galaxy; successful compilation does not establish device compatibility.

Test Windowed Glass at 100% strength with Smooth (120 ms): slowly close from fully open, then repeat at normal speed. Check whether the inner dark edge continues moving inward as the image stretches. Also check a quick close for the separate cover-startup flash. Copy the status report after a problematic fold. A second camera is not required.

Root test (rooted devices only): select Use existing root access, grant the root manager prompt, then apply/verify the required wallpaper and reconnect helpers. Confirm the connection report selects Root, angle replies report UID 0, and keep-awake is verified. Test cold start, app restart, reboot and returning to Shizuku. Root support remains experimental until these on-device checks pass.
