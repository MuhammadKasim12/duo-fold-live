# Duo Fold Live 3.5.5-alpha.30 — prepared cover compositor bridge

Experimental pre-release; alpha.20 remains the stable rollback baseline.

Alpha.29 device testing still showed the flash. All five recorded closing bridges first drew into an inner-sized app view, then crossed a surface resize. This build adds a separate helper-owned cover-sized buffer before the primary switch, independent of that SurfaceView.

- Prepare a hidden, opaque, center-cropped blurred copy of recent inner content while the inner panel remains primary. It is temporary outgoing content, not a live cover capture.
- Show/commit the prepared layer on the cover stack before requesting the closing handoff. The nonblocking gate waits at most 80 ms; unavailable/stale preparation skips it. Existing handoff angle and hysteresis remain unchanged.
- Follow the cover's physical identity across the layer-stack remap using a fixed-size buffer. Polling and transaction timing can still leave a visibility gap; this is an experiment, not a guarantee.
- Keep it for at most 600 ms, fading over 80 ms after a fresh, correctly sized cover frame commits. Reject old-handoff, wrong-panel, wrong-rotation, future, and stale readiness. Clear at closure, reversal, lock, lost mapping, inactive lease, or shutdown.
- Exclude this owned layer from capture. Keep the existing renderer on the main thread and retain alpha.29's geometry and transient-OFF fixes.
- Add PREPARE, ARM, PRE_SWITCH_COMMIT, RETARGET_COMMIT, FRESH_COVER_COMMIT and CLEAR records. Transaction callbacks are software evidence, not visible-pixel proof.

Validation: shader/curve checks and CI unit tests, lint, release assembly, APK signing verification. Optical behavior requires device testing.

Test several slow and normal-speed inner-to-cover folds, including a reversal near handoff, on Home and a fullscreen app. Report whether the clear flash remains, whether a brief frozen blur appears, and any dark/stuck layer. Copy the status after each context. This opaque temporary blur can look different from the animated glass cutouts during its short hold.
