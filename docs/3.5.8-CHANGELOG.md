# Duo Fold Live 3.5.8

Promotes the tested 3.5.8-alpha.15 source to main/stable with one behavior change: Inner screen motion glass is enabled by default. This is applied once on install/update; subsequent user choices are preserved.

All other application behavior is retained from alpha.15. Version metadata and stable-release publishing configuration are updated for this release. Additional display-off diagnostics are deferred to a future alpha.

Validation: signed-release CI runs unit tests, lint, renderer regression checks, release audit, APK signing and signature verification.
