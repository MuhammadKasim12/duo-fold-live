# alpha.39 — Plain Fade

Plain Fade now uses full-panel black with a square-root onset (about 24% opacity after 5 degrees) on both screens. Black reaches full opacity at the configured handoff angle. An opaque secondary inner presentation covers content while the cover remains primary, with no preview or wallpaper content. Other styles retain their existing curves. Verify physical panel activation for any frame before the black window attaches; software tests cannot prove absence of hardware transition flashes.
