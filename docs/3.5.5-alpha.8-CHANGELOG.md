# Duo Fold Live 3.5.5-alpha.8

Use the existing Live Screen renderer on the incoming panel.

- The incoming panel now passes its verified live capture to the same attached FrostSurface renderer used by normal Live Screen mode. It no longer routes live frames through the frozen-frame/window-buffer painter or adds a full-screen screenshot backdrop.
- Reuses normal live shader opacity, clean-half behavior, direct hinge/vsync updates, frame age/size/rotation checks, and registration of the actual animation surface for capture exclusion. Capture routing still targets D1 during the concurrent session.
- Preserves exact-app and physical-panel verification before rendering incoming content. Carries rotation from the first verified capture into the live frame checks.
- Keeps secondary screenshot surfaces out of the normal cover-preview bridge on resize, matching the existing creation guard.
- The outgoing panel retains its frozen screenshot. Task routing, endpoint power handling, normal Live Screen behavior and wallpaper wake preparation are unchanged.

The previous approach shared the shader but used a different renderer for incoming content. This build removes that difference; it does not establish the optical root cause without handset testing.
