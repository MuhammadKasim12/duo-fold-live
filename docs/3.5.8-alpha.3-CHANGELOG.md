# 3.5.8-alpha.3 — Inner motion glass by default

- Normal settings now control inner screen motion glass, including its sensitivity. Existing inner enablement and sensitivity are preserved.
- Cover motion glass moves to Developer settings with its own experimental toggle and sensitivity. Its new toggle defaults OFF on upgrades and new installs.
- Disabled cover motion produces zero tilt offset; the normal hinge-driven glass animation remains.
- Reflected glass on the inner display still follows the inner motion setting.
- Cover experiment can run independently of inner enablement. Direction and smoothing remain shared. Resetting normal motion settings no longer changes cover sensitivity.
- Status reports identify both enablement states. Alpha.1 startup settling and dead zone remain.
- GitHub prerelease only; stable and Play unchanged.
