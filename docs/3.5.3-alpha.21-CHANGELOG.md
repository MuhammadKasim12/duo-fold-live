Read-only diagnostics; no handoff, power, rendering, or settings-default changes.

- Retain the last six endpoint summaries separately from verbose traces.
- Learn cover/inner physical IDs and dimensions from the pre-endpoint display pair, then follow the incoming physical panel across D1/D0 remapping. Missing or duplicate identity is explicitly unknown.
- Report sampled OFF/ON times, estimated OFF bounds when observations allow, first D0 mapping, first D0 ON with destination dimensions, maximum sampling gap, and whether noninteractive state occurred.
- Correlate exact-app window READY dump intervals with the endpoint timestamp as well as remapping. READY is neither first-frame nor optical proof.

Test with existing switches unchanged, Samsung ON hold OFF and closing app-first return ON. Start in an unlocked fullscreen app; open fully, wait five seconds, close fully, wait five seconds. Repeat twice and copy the short status report. Note whether the black gap precedes a frozen image or immediately resumes live content. Home routing should be tested separately.

Software sampling can miss short transitions; estimated bounds assume no unobserved intervening state changes. Physical blackout duration still requires an external camera.
