# 3.5.3-alpha.36

- Added a Notifications section with a direct link to Samsung/Android settings for the persistent running notification category. Android owns this visibility setting; foreground service promotion remains intact.
- Added an independent Support notifications switch, enabled by default. Disabling it cancels an existing support notification and prevents scheduled and preview notifications without resetting the invitation schedule or changing in-app reminders.
- Animation, Quick Settings toggle, capture recovery and wallpaper behavior are unchanged.

Device checks: hide/re-enable the running category, verify folding and Quick Settings still work, disable support notifications and check previews stay suppressed, restart and verify preferences persist.
