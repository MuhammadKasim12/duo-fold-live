# 3.5.8-alpha.4 — Snappy inner return and earlier tilt reference

- Inner return is now a 60 ms cubic ease-out instead of a 300 ms smoothstep.
- Folds starting in the upper half of the hinge range lock the first fresh rotation sample immediately, preserving subsequent closing rotation instead of absorbing it during startup settling.
- Folds starting in the lower half retain 120–350 ms settling. Sensor-gap recovery still settles; dead zone, sensitivity and smoothing remain unchanged.
- This remains a relative-rotation approximation, not hand detection or guaranteed world-locked projection. Motion before sensor registration is not recovered. Validate both folding directions on the phone.
- Cover motion remains a disabled-by-default developer experiment. Stable and Play unchanged.
