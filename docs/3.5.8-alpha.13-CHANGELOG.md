# 3.5.8-alpha.13

Fix notification background blur initialization on modern Android. Alpha.12 requested the obsolete WindowlessWindowManager(Configuration, SurfaceControl, IBinder) constructor and fell back to projection on the test handset.

Select the known InputTransferToken signature first, retaining the IBinder signature for older firmware. Unknown signatures fail explicitly and report available constructors. Log the selected signature and successful host creation. Preserve non-touchable/non-focusable window flags, notification blur recipe, experimental mode selection, and rotation-recovery placement.

Reference: AOSP core/java/android/view/WindowlessWindowManager.java and SurfaceControlViewHost.java (current source). Modern AOSP uses InputTransferToken and permits a null host token through SurfaceControlViewHost.

Validation: CI compilation, unit tests, lint, release audit and APK signing. Device validation still required: select notification background blur + stretch during a partial fold; verify Samsung API accepted status and compare against projection-only. Generic GLASS_COMMIT alone does not establish blur activation or visible pixels.
